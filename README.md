[EMU-Script](https://sylvain-pearson.github.io/EMU-Script) is a text-based, electronic music composition software for MacOS. 

- Built-in script editor with syntax highlighting and error checking.
- Multi-track MIDI sequencer.
- Sheet music viewer that automatically scrolls during playback.
- Control your virtual instruments and external synthesizer using MIDI messages (MIDI note, control change, and program change).
- Structure your composition using musical sections and sequencing functions.
- Use chord progressions, strum chords, and play arpeggios.
- Specific notation for drum instruments.

## Release
You can download the latest version of the application using this link: [version 1.2](https://github.com/sylvain-pearson/EMU-Script/releases/download/EMU_V1.2/EMU-Script.app.zip)

What's new in this version:
 - Zoom-in and zoom-out in sheet music.
 - Staff with 1, 2, or 3 octaves.
 - Sheet music with a clear background, even in dark mode.
 - Improved error display.
 - Play a measure in unison.
 - Per instrument CC definitions
 - Changed syntax of sequence parameters ($).
 - Improved iPad support (but still not production ready).
 - Bug fixes.

## Requirements
- Xcode version 26 or higher is required to build the application.
- Minimum required MacOS version: 26
- A synthesizer or virtual instrument (MIDI compatible; plugins are not supported). 
- If you want to record your music creation, you need an audio mixing application.
